(A) DO THE NUMERIC COLUMNS ALIGN WHEN READ STRAIGHT DOWN?

  MODEL LIST — YES. Measured mechanically from the width-140/30d render above:
  every one of the 8 model rows ends at exactly column 136. The figures are
  right-aligned to a shared end column, which is why '$90.73' and '$0 · 210 req'
  both finish in the same place despite very different lengths.

  STAT STRIP — YES, but on a DIFFERENT and correct rule. The strip is a grid of
  EQUAL-WIDTH COLUMNS, so each figure sits at the same offset inside its column
  and consecutive figures are spaced by exactly one column plus one gutter.
  At width 140 that reads:
      requests    65,460    cost        $112.36   error rate  2.01%     cache share 95.9%
  — even intervals, which is the property the eye uses.

  What is deliberately NOT claimed: the four figures do NOT share one absolute
  column, and cannot. Cell i begins at i x (column + gutter), so only the row's
  LAST cell reaches the right edge. Right-aligning every figure to a single
  absolute column is possible only for a row holding ONE cell, which is the model
  list's shape and not a strip's. An earlier version of this screen joined whole
  cells with three spaces and let them fall where they fell, which put the figures
  at columns 11, 27, 51 and 73 — no two comparable. That is fixed and tested.
